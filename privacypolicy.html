01 Information We Collect

Wuys Bot collects and stores the following types of data:

1.1 User Data

  • User ID: your unique Discord identifier, used to associate your account with features like economy balances, warnings, marriages, and cooldowns.
  • Username and Display Name: stored temporarily for display purposes in logs and messages.
  • Avatar URL: used for embeds and welcome/goodbye messages.
  • Voice State Information: used for Join-to-Create (JTC) voice channel management.

1.2 Server (Guild) Data

  • Guild ID: used to store server-specific settings and configurations.
  • Channel IDs: used to store log channels, welcome channels, ticket panels, and JTC trigger channels.
  • Role IDs: used for auto-roles, reaction roles, and ticket staff roles.
  • Message IDs: used for reaction role panels and giveaway tracking.

1.3 Content Data

  • Message Content: temporarily processed for mention responses (personality replies when the Bot is mentioned), logging (deleted/edited messages sent to configured channels), and ticket transcripts (full message history saved as HTML for moderation purposes).
  • Command Inputs: user-provided arguments for commands (e.g., warning reasons, giveaway prizes, custom messages).

1.4 Economy Data

  • Wuys Coins (WC) Balance: wallet and bank balances are stored per user.
  • Cooldown Timestamps: daily and work command cooldowns are tracked to prevent abuse.
  • Casino Statistics: wins and losses for casino games are recorded.
  • Transaction History: not stored in detail, but changes to balances are logged internally for administrative purposes.

1.5 Relationship Data

  • Marriages: active marriage relationships between users.
  • Slave Relations: roleplay slave-master relationships (for entertainment purposes only).

1.6 Customization Data

  • Bot Customization: per-server bio, avatar, banner, and nickname settings.
  • Welcome/Goodbye Messages: custom templates stored per server.
  • Log Settings: per-guild log channel configuration and per-category toggles.

03 Data Storage

3.1 Storage Methods

  • SQLite Database (wuys.db): stores structured data such as warnings, settings, tickets, reaction roles, and giveaways.
  • JSON Files (/casinodata/): stores economy data (balances, cooldowns, statistics) per user.
  • File System: stores logs (/logs/wuys.log), ticket HTML transcripts (/transcripts/ticket_*.html), and assets — bot avatar, banner, and meme files (user-uploaded).

3.2 Storage Location

All data is stored on the server hosting the Bot. Data is not stored on third-party cloud services unless explicitly stated.

3.3 Data Retention

  • Warnings: retained indefinitely for moderation purposes unless manually deleted by an administrator.
  • Economy Data: retained until the user requests deletion or the account becomes inactive.
  • Logs: retained for 30–90 days (depending on server configuration) for troubleshooting and moderation.
  • Ticket Transcripts: retained indefinitely unless deleted by server administrators.

04 Data Sharing and Disclosure

4.1 Third-Party Access

We do not sell, trade, or rent your personal data to third parties. Your data is only accessible to:

  • Bot Owner/Developer: for maintenance, debugging, and support.
  • Server Administrators: they can view logs, warnings, and ticket transcripts on their own servers.
  • Discord: as required to process commands and interact with the Discord API.

4.2 Legal Compliance

We may disclose your data if required by law or in response to valid legal requests (e.g., court orders, government regulations).

05 Your Rights and Choices

5.1 Right to Access

You can view your own data through commands like /balance, /warnings, and /userinfo. Server administrators can view more extensive logs and settings.

5.2 Right to Rectification

You can update your preferences using commands like /customize (for server admins) or by reconfiguring settings.

5.3 Right to Deletion

You may request deletion of your data by contacting the Bot Owner via Discord with your request, or by asking a server administrator to manually delete warnings, tickets, and other server-specific data.

Response time

Upon verified request, we will delete all personally identifiable data related to you within 14 days.

5.4 Right to Withdraw Consent

You may withdraw your consent to data processing by removing the Bot from your server or ceasing to use its features.

06 Data Security

We take reasonable measures to protect your data:

  • Database Encryption: the SQLite database is not encrypted by default, but access is restricted to the Bot process.
  • File Permissions: sensitive folders (/casinodata/, /logs/, /transcripts/) are restricted from public access.
  • Logging: all administrative actions are logged for accountability.
  • Regular Backups: data is backed up regularly to prevent loss (frequency depends on server configuration).

However, no method of transmission over the Internet or electronic storage is 100% secure. While we strive to use commercially acceptable means to protect your data, we cannot guarantee absolute security.
